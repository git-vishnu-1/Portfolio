# Portfolio

Personal portfolio website showcasing my work, skills, and projects.

## Tech Stack
- HTML
- CSS
- JavaScript

## Features
- Responsive layout
- Light / Dark mode
- Subtle animations
- Clean, accessible UI

## Adding a Profile Photo
Add your portrait to the project root as `profile.jpg`. The hero section automatically displays it as a circular 128px image on desktop and a 96px image on mobile. A square image works best; the existing layout and theme styles are preserved.
